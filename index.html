CONNECTION WORKFLOW

PAIRING & SETUP

Pairing tidak dilakukan dari HTML. Gunakan dua sesi Termux seperti biasa.
1 · TargetJalankan node receiver.js di Termux Target.
2 · ControllerJalankan node controller.js di Termux Controller.
3 · PairingMasukkan IP Target, port 47831, PIN 6 digit di Controller.
4 · ApprovalDi Target periksa IP Controller lalu ketik y untuk menyetujui.
5 · TunnelController mencoba menjalankan cloudflared ke bridge lokal port 47834.
6 · DashboardBuka link HTML dari bagian atas menu Termux; masukkan Web Access Code.
Jangan bagikan URL tunnel dan kode akses. Keduanya memberi jalur ke sesi Controller yang sudah dipasangkan. Putuskan dashboard atau sesi Termux saat selesai.
